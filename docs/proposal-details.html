PRE-CONFERENCE WORKSHOP

Text Mining Systematic Reviews

A Deterministic, Evidence-Based LLM Pipeline for Knowledge Extraction

1. Workshop Overview

Abstract

This hands-on workshop teaches participants how to download scientific articles in bulk and analyze them using an evidence-based, deterministic LLM pipeline with no generative AI. Combining API-based paper retrieval, PDF-to-text conversion, classical NLP preprocessing, and transformer-based causal relation extraction, attendees will build a fully transparent and reproducible pipeline for text mining systematic reviews. The workshop culminates in the construction of a causal knowledge graph (nomological map) derived from published scientific claims, using the SocioCauseNet model for structured relation extraction.

Who Should Attend

This workshop is designed for social science PhD students and researchers who want to bring computational tools into their review and theory-building work. It is also open to anyone curious about using text mining methods to make systematic reviews faster, more reproducible, and more transparent. No prior experience with NLP or machine learning is needed. If you can write a little Python, you are ready to follow along.

This workshop is relevant for anyone interested in:

  • Knowledge extraction from published scientific papers

  • Automating qualitative systematic reviews

  • Transparent and reproducible text analysis

  • Constructing theory from published causal claims

  • Creating a nomological map for a research area

Learning Objectives

By the end of this workshop, participants will be able to:

  • Retrieve scientific papers programmatically in bulk using public APIs (Semantic Scholar, PubMed, CrossRef)

  • Convert PDF documents to clean, structured text for downstream processing

  • Apply NLP preprocessing pipelines using spaCy and NLTK

  • Understand the distinction between sentence-level and token-level transformer models

  • Use HuggingFace Transformers and Sentence Transformers for deterministic, non-generative text analysis

  • Run the SocioCauseNet model to extract causal relations from scientific sentences

  • Harmonize extracted relations and construct a nomological knowledge graph from published causal claims

Format & Structure

  • Format: In-person pre-conference workshop
  • Approach: Evidence-based, deterministic LLM pipeline (no generative AI)
  • Structure: 5 modules: brief lecture overviews + hands-on Jupyter notebooks
  • Prerequisites: Python basics; Jupyter/Colab environment; pip install access
  • Partners: Netherlands eScience Center · Open Science Community Tilburg

3. Detailed Module Descriptions

Module 1: Bulk Paper Retrieval via API

Duration: [TBD] | Format: Lecture + Hands-on Notebook

Conceptual Overview

We start from the very beginning: getting papers. This module introduces the eScience Center package for bulk downloading of scientific articles, which is specifically designed to make large-scale retrieval straightforward for researchers without a systems background. Before diving into the downloading itself, we walk through how to set up your API keys, understand what the tool can do, and make sense of the different options available to you. By the end of this module, you will have a working setup and a local collection of papers ready for the next steps.

Topics Covered

  • Setting up API keys and configuring your environment
  • Introduction to the eScience Center bulk download package: what it does and how it works
  • Exploring the features: search filters, metadata retrieval, and download options
  • Running your first bulk download and organizing the output
  • Handling common issues: missing papers, access restrictions, and rate limits

Hands-on Exercise

Exercise 1: Set up your API keys, explore the eScience package features together, and run a bulk download on a topic of your choice. You will end the session with a folder of papers and a metadata file ready to use in the next module.

Module 2: PDF to Text Conversion

Duration: [TBD] | Format: Lecture + Hands-on Notebook

Conceptual Overview

Once you have your papers, the next challenge is getting the text out. PDFs are notoriously messy, and scientific papers make it even harder with multi-column layouts, figures, tables, and reference sections. In this module we take a tour of the most widely used PDF-to-text tools, including some newer options that have become popular recently, and compare what they are each good at. We will pick one tool together and use it to extract the text we need, keeping the focus practical rather than exhaustive.

Topics Covered

  • A guided tour of PDF-to-text tools: PyMuPDF, pdfminer, pdfplumber, GROBID, and a look at newer alternatives
  • What each tool handles well and where each one struggles
  • Choosing the right tool for scientific papers
  • Running the extraction on your downloaded corpus
  • Basic cleaning: removing headers, footers, reference sections, and broken line breaks

Hands-on Exercise

Exercise 2: Convert your downloaded PDFs to plain text using the tool we select together. We will inspect the output, clean up common problems, and save a text corpus that is ready to feed into the NLP pipeline.

Module 3: NLP Tooling & Preprocessing

Duration: [TBD] | Format: Lecture + Hands-on Notebook

Conceptual Overview

The SocioCausaNet model works at the sentence level. It takes a single sentence and decides two things: first, whether that sentence contains a causal claim, and second, if it does, what the cause and the effect are. That means our job in this module is simple but important: take the raw text from our papers and split it into clean, well-formed sentences. We will walk through a few light preprocessing steps that make the sentences easier for the model to work with, and by the end you will have a sentence dataset that is ready to hand off to the model in Module 5.

Topics Covered

  • Why sentence segmentation matters for causal extraction
  • Using spaCy to split paper text into sentences reliably
  • Handling tricky cases: abbreviations, citations inline, and broken sentences from PDF extraction
  • A few simple preprocessing steps: stripping noise, normalizing whitespace, filtering very short or very long sentences
  • Building a clean sentence-level dataset from your paper corpus

Hands-on Exercise

Exercise 3: Take your extracted paper texts, run them through a sentence segmentation pipeline, apply a few preprocessing steps, and produce a final list of sentences. This dataset will be exactly what we feed into SocioCausaNet in the last module.

Module 4: HuggingFace & Transformer Models

Duration: [TBD] | Format: Lecture + Hands-on Notebook

Conceptual Overview

HuggingFace has become the go-to place for sharing and using pre-trained NLP models, and this module is your introduction to it. We will spend time exploring the HuggingFace Hub together: how to search for models, how to read a model card, and how to understand what a model was trained to do. From there we will briefly cover the two main types of models you will encounter in this kind of work: sentence-level models that produce a single embedding for a piece of text, and token-level models that label each word individually. The goal here is not to go deep into the technical details, but to give you enough familiarity that you can find and use models on your own after the workshop.

Topics Covered

  • Navigating the HuggingFace Hub: searching for models, reading model cards, and filtering by task
  • Understanding model tasks: text classification, token classification, feature extraction
  • Sentence Transformers: what they produce and when they are useful
  • Token-level models: how they label text word by word
  • Using the HuggingFace pipeline API to run a model in just a few lines of code
  • Finding the right model for social science text (SciBERT, domain-specific options)

Hands-on Exercise

Exercise 4: Browse the HuggingFace Hub together, find the rasoultilburg/SocioCausaNet model page, read its model card, and run your first inference using the pipeline API on a handful of sentences. No deep setup required.

Module 5: Causal Relation Extraction & Knowledge Graph Construction

Duration: [TBD] | Format: Lecture + Hands-on Notebook

Conceptual Overview

This is where everything comes together. We run SocioCausaNet on the sentence dataset we built in Module 3, and for every sentence flagged as causal, the model gives us a cause and an effect. But raw model output is messy: the same concept might appear in dozens of slightly different wordings across hundreds of papers. This module focuses on how to harmonize those extracted social science constructs so that they refer to the same node in our knowledge graph. Once harmonized, we build a graphical representation of the causal knowledge in our corpus and learn how to query it to answer questions like: what factors does the literature say influence wellbeing, or what downstream effects does stress have? The result is a visual nomological map of a research area, built entirely from published evidence.

Topics Covered

  • Running rasoultilburg/SocioCausaNet on your sentence dataset
  • Understanding the model output: causal label, cause span, and effect span
  • Harmonizing social science constructs: grouping synonymous terms into shared nodes
  • Building the knowledge graph: concepts as nodes, causal relations as edges
  • Adding provenance: linking each edge back to the paper and sentence it came from
  • Graphical presentation: visualizing the nomological map of your research area
  • Querying the graph: finding influential constructs, causal chains, and research gaps

Hands-on Exercise

Exercise 5: Run the full pipeline end to end: feed your sentences into SocioCausaNet, harmonize the extracted constructs, and build a causal knowledge graph. Visualize the network and run a few example queries. You will leave with a working nomological map derived entirely from published scientific claims.

4. Logistics & Requirements

Technical Requirements

Participants must bring a laptop with:

  • Python 3.9+ installed (Anaconda or venv recommended)
  • Jupyter Notebook or access to Google Colab
  • Internet access for API calls and model downloads
  • Minimum 8 GB RAM (16 GB recommended for local model inference)

Required Python packages (install guide provided in advance):

requests | pandas | PyMuPDF | grobid-client | spacy | nltk | transformers | sentence-transformers | torch | networkx | matplotlib | tqdm

Organizer Requirements

  • Projector / large screen for live coding demonstrations

  • Stable Wi-Fi connection for all participants

  • GitHub repository with all notebooks distributed in advance

  • Optional: pre-downloaded model weights for participants with slow connections
